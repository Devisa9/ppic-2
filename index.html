Aplikasi membaca data berdasarkan nama header kolom (huruf besar/kecil bebas). Baris pertama harus header. Satu file Excel boleh berisi beberapa sheet.

The app reads data by column header names (case-insensitive). The first row must be the header. One Excel file may contain several sheets.
